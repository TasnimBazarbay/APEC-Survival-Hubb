# APEC Radar 
Система мониторинга и управления инфраструктурой колледжа APEC.

### Функции:
- Подача заявок студентами через Google Auth.
- Админ-панель с Real-time обновлением (Firebase).
- Smart Analysis для выявления критических поломок.

### Технологии:
- Python (Flask)
- Firebase Realtime Database & Auth
- HTML5/CSS3 (Glassmorphism design)
